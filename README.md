# DoIt

> 🗄️ **Archived learning project.** Built in 2017 while taking an introductory iOS course, kept as-is as a snapshot of where I started. It targets Swift 3 / iOS 10 and won't build in current Xcode without migration.

A simple to-do list (May 2017). It shows a list of tasks, adds new ones with an "important" flag (shown with a `!` prefix), and completes a task to remove it.

**What I learned:** table views, a custom model class, navigation-controller flows across three screens, and handing data back to the previous screen.

**Stack:** Swift 3 · UIKit · Storyboards · iOS 10.3

Tasks live in memory only. The Core Data step of the course was never finished (see the last commit: *"Working app, without CoreData"*).
